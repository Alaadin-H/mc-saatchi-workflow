⚡ Supabase Database Setup

Connect your project to Supabase to enable free cloud storage, real-time collaboration, and automatic task ID generation.

Quick Setup Steps:
  1. Create a free account and project at supabase.com.
  2. In Supabase, open the SQL Editor tab on the left.
  3. Copy the contents of supabase-schema.sql and click Run.
  4. Go to Project Settings → API, copy your Project URL and anon public key, and paste them above.
